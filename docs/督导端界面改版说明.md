# 督导端界面改版说明

## 与教师端一致的交互
- 顶部身份切换与刷新按钮。
- 清晰分区：筛选区、概览指标、数据列表（保留原项目深蓝色顶栏与白色卡片体系）。
- 支持学期、课程、发布状态、关键词检索。学期与课程列表从数据库动态读取，减少输入错误。
- 增加快捷状态切换、点击查看开课详情、导出当前筛选结果CSV。

## 权限边界
本次用户故事名称为“教学督导端查看课程开设情况”，没有包含修改开课计划或发布课程大纲。为避免越权，相关写入行为仍由教师端和教研室主任端按既有权限执行。导出属于非修改操作。

## 测试
保留原来的258项测试，新增筛选接口的正常返回、非督导身份拒绝、缺少身份拒绝，共计261项。
