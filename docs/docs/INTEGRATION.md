这些内容仅说明团队后续对接方向，并非声明它们已经通过本 Sprint 验收。

## API 兼容约定

- 所有读接口遵循 `/api/v1/` 前缀，响应统一为 `{"code", "message", "data"}`。
- 业务异常一律抛 `BusinessError`，由 `公共基础模块/errors.py` 统一转换为 HTTP 状态码，不在各模块重复写异常处理。
- 其他角色端请创建独立路由文件，复用 `公共基础模块/db.py` 的 `get_db`，避免重复建立数据库连接。
- 新增角色端鉴权时，请复用 `公共基础模块/auth.py` 的 `_resolve_demo_role`，保持 `AUTH_REQUIRED` / `USER_UNKNOWN` / `ROLE_FORBIDDEN` 三个错误码一致。

## 数据模型约定

- 教师端新增 `course_teachers(course_id, teacher_id, duty)` 授课关系表，是**纯新增结构**：旧的 `sprint1.sqlite3` 备份库可被 `schema.sql` 的 `CREATE TABLE IF NOT EXISTS` 直接升级，无需手工迁移。
- `courses.teacher_name` 保留为面向学生的展示名；**授课归属以 `course_teachers` 为准**，请其他模块不要用 `teacher_name` 做权限判断。
- 所有“按课程 id”访问的接口必须先做归属校验，并对“不存在”和“无权访问”返回**同一个错误码**，避免通过报错差异探测他人数据。

## 用户故事验收建议

1. 给定教师 `T003`（主讲 SE201、协讲 MA101），第 1 周课表有两项且按星期排序；第 19 周只剩 MA101。
2. 给定教师 `T001`（本轮未排课），课程列表与课表均为空，访问任意课程返回 404。
3. 给定教师 `T005`（AI999 主讲），可查看未发布草稿、保存后发布；发布后学生 `S2024001` 可立即读到。
4. 给定教师 `T003` 访问 `CS101`（李老师的课），列表、课表、名单、大纲接口一律 404。
5. 给角色为主任/督导/学生的身份访问教师端接口，返回 403。
6. 给非法教学周或非法大纲字段，返回标准 422；数据库断开返回不泄漏细节的标准 503。

## 已知限制

这是虚构数据教学原型，尚无真实授权身份上下文、正式数据库迁移方案、跨服务集成测试、可观察性与性能测试。自动测试不覆盖浏览器端 DOM 行为，页面交互仍需人工演示确认。
