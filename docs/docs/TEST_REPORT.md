## 教师端重点场景

- **权限边界**：张老师（T003）看不到李老师（T002）的 `CS101`；未排课的教师甲（T001）访问任何课程均 404；越权写入他人大纲时既返回 404 又不改变原数据。
- **身份场景**：缺失、空值、纯空白、未知标识、SQL 注入式标识，学生与教师两端行为一致。
- **课表边界**：第 19 周起 `SE201` 结束只剩 `MA101`；第 20 周仍含 `MA101`；同一排课行命中多条授课关系时不重复展示。
- **大纲状态机**：草稿 → 发布 → 锁定（不可改）→ 撤回 → 可改；重复发布、撤回未发布、草稿缺失、字段缺失/空白/超长/类型错误均返回稳定错误码，且校验失败不落库。
- **跨端一致性**：教师发布 `AI999` 大纲后，学生端 `S2024001` 可立即读到同一份内容。
