# Sprint1四端集成交付说明

## 范围和来源

原始压缩包包含学生端、教师端、教研室主任端。此增量增加教学督导端**查看课程开设情况**一项业务功能；不创建督导评价、巡课、课程编辑等未要求功能。

## 运行（Windows PowerShell）

```powershell
py -3 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe run.py
```

浏览器打开 http://127.0.0.1:8000/portal 进入四端导航。

- 学生端：http://127.0.0.1:8000/student
- 教师端：http://127.0.0.1:8000/teacher
- 教研室主任端：http://127.0.0.1:8000/director
- 教学督导端：http://127.0.0.1:8000/supervisor

原项目 `/` 继续跳转学生端，避免已有回归用例失效。

## 督导端功能

- 可查询全校学期开课信息（课程编号、名称、学分、教学班、学期、任课教师、大纲状态、课程选课人数）。
- 支持按课程编号/名称/教学班模糊搜索、学期和大纲发布状态过滤、分页，含空结果状态。
- 显示当前条件下开课教学班数、涉及课程数、已发布大纲教学班数、未发布大纲教学班数。注意大纲发布统计单位是开课教学班，不是课程。
- 展示多教师授课名单，但单个教学班只计一次开课记录。
- 只读API，不向教学督导开放课程变更接口。

## 督导端API

`GET /api/v1/supervisors/me/offerings`

请求头：`X-Demo-User: V001`。可选查询参数：`keyword`（最多80字）、`semester`（形如2026-2027-1，需为连续学年）、`outline_status`（all/published/unpublished）、`page`（1~100000）、`page_size`（1~100）。

演示角色由已有公共 `users` 表控制；缺失身份为401，非督导为403，非法查询参数为422，数据库错误统一为503。`X-Demo-User` 是课堂演示身份标识，**不属于生产安全认证**。
