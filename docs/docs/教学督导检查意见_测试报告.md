# 教学督导端检查意见功能测试报告

## 功能范围
查看课程及课程详情；在指定开课教学班中新增检查意见并查看历史。检查意见含检查类型、检查结论、正文、督导人员和时间，写入共享SQLite数据库；不允许修改原课程和教学大纲。

## 运行验证
命令：`python -m pytest -q 测试代码 --disable-warnings`

结果：**276 passed**（原261项，新增加15项）。

## 新增测试覆盖
- 正常：创建与持久化、历史顺序、教学班间隔离、页面展示、查询资料不被修改。
- 权限：无身份401、未知身份401、学生/教师/主任读取或提交403。
- 异常：不存在教学班404，文本为空/长度不足/超过上限422，非法类别和结论422，缺失字段/错误JSON422、异常编号校验。
- 安全：含HTML字符的检查正文当作文本存储，页面通过`textContent`安全呈现。

## 限制
课堂演示环境使用`X-Demo-User`身份头，不等同于真实登录认证。正式上线前需替换为安全登录鉴权；本测试结果不代表生产环境安全评估或真实浏览器端到端测试。
